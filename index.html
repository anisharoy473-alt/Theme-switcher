A Simple Way to Change Your Website's Look.

ColourSwitch is a beginner-level web development project created using HTML, CSS and JavaScript. It allows users to change the appearance of a website by selecting different colour themes. This project helped me understand JavaScript functions, conditional statements and DOM manipulation.
